## Claude Copilot for Ansys Maxwell

I want to build a Claude-powered copilot that connects to Ansys Maxwell so users can design products from natural-language prompts.

### Core idea
- Let users describe design goals in plain language.
- Translate prompts into Maxwell setup steps (geometry, materials, excitations, and solver settings).
- Run in a sandbox mode first, with optional account-connected mode for full project workflows.

### Target outcome
Create a guided AI assistant experience inside (or alongside) Ansys Maxwell that helps engineers move from prompt to simulation-ready design faster.
